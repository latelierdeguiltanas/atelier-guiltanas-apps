Réparer les notifications Android

  1. Dans Samsung Internet : menu ☰ → Paramètres → Notifications → Gestion des notifications de sites (le libellé varie) et autorise latelierdeguiltanas.github.io.
  2. Vérifie aussi Paramètres du Samsung → Applications → Samsung Internet → Notifications et autorise les catégories de notifications du navigateur.
  3. Reviens sur MJ Express et relance « Activer les notifications », puis le test local.

Les permissions web s'appliquent au domaine entier de GitHub Pages, pas uniquement à MJ Express. Ne supprime pas les données du site : cela pourrait déconnecter tes autres outils et effacer des données locales.

Cette opération ne supprime ni tes personnages ni les données des hubs.
