## Exécution et limites

Le workflow `forge-n1-arq-source-fixes.yml` construit les HTML depuis les sources, rejoue les contrôles et les vrais clics Chrome tactile avant publication. Les conflits de rapports JSON sont résolus avec les résultats du run ; aucun conflit de code ou de produit n’est résolu automatiquement.

Le modèle officiel est passé en argument privé à `n1_arq_official_template.cjs` ; les sorties restent temporaires. Le produit maître interne ne contient pas le module d’export officiel de l’entrée publiée ; le test PDF vise explicitement index.html et les exporteurs natif/partagé, sans prétendre certifier ce module absent du maître.

Restent notamment toutes les variantes d’équipement et des dons, effets historiques complets, PDF peuples/historiques, et certificat source/effets/parcours des treize autres profils. Les scores ne sont pas augmentés par le seul nombre de tests ou par la présence de texte.
